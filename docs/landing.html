⚡ Getting Started

Quick Start Guide

Get started with the KPM Academy API in 3 simple steps.

1

Register / Login

Create a new account or sign in with an existing email to receive your JWT access and refresh tokens.

2

Get Token

Save the access_token from the response. Include it in every request header: Authorization: Bearer <token>

3

Make Requests

Access all API endpoints. Use the refresh_token to obtain a new access token when the current one expires.

# Register new user curl -X POST https://backend-api.kpmacademic.io/api/v1/auth/register \ -H "Content-Type: application/json" \ -d '{ "name": "Ahmad Fauzi", "email": "ahmad@kpm.ac.id", "password": "Secure@123", "phone": "08123456789" }' # Login curl -X POST https://backend-api.kpmacademic.io/api/v1/auth/login \ -H "Content-Type: application/json" \ -d '{"email": "ahmad@kpm.ac.id", "password": "Secure@123"}' # Use token for authenticated requests curl https://backend-api.kpmacademic.io/api/v1/profile \ -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
// Register & Login const register = async () => { const res = await fetch('https://backend-api.kpmacademic.io/api/v1/auth/register', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ name: 'Ahmad Fauzi', email: 'ahmad@kpm.ac.id', password: 'Secure@123' }) }); const { data } = await res.json(); const token = data.tokens.access_token; // Use token const profile = await fetch('https://backend-api.kpmacademic.io/api/v1/profile', { headers: { 'Authorization': `Bearer ${token}` } }); };
import requests # Register res = requests.post("https://backend-api.kpmacademic.io/api/v1/auth/register", json={ "name": "Ahmad Fauzi", "email": "ahmad@kpm.ac.id", "password": "Secure@123" }) token = res.json()["data"]["tokens"]["access_token"] # Authenticated request profile = requests.get( "https://backend-api.kpmacademic.io/api/v1/profile", headers={"Authorization": f"Bearer {token}"} )

🔒 Authentication

JWT Authentication Flow

JWT-based authentication with access and refresh token rotation.

Authentication Flow
Login to receive a token pair, use the access token for requests, and refresh when expired.

POST /auth/login

Send email + password. Response contains access_token (1 hour) and refresh_token (7 days).

Request with Bearer Token

Include the header Authorization: Bearer <access_token> in every authenticated request.

POST /auth/refresh-token

Send the refresh_token to get a new token pair. The old token is automatically invalidated (single-use rotation).

POST /auth/logout

Invalidates the refresh token. The user must log in again to obtain new tokens.
